# Anthrax-and-Scavengers
Code in this repository is affiliated with math and epi models incorporating carnivores and scavengers into anthrax outbreaks. Manuscripts affiliated with this repository include:

1.) Mitchell, S., Flaxman, A.D., Laubach, Z.M. et al. A One Health model evaluating the role of a wild carnivore in mitigating multi-host anthrax outbreaks. Sci Rep (2026). https://doi.org/10.1038/s41598-026-65464-x

2.) Kendall, C. J., Crews, S., Bracebridge, C., Mgumba, M., Stears, K., Epaphras, A., & Mitchell, S. (2026). Individual variation in vulture use of an anthrax outbreak: implications for biomass removal. Manuscript in preparation for submission to Ecosystem Services


### How to Cite

If you use or adapt code from this repository in your research, please cite this repository and the corresponding publication(s) associated with the analysis you used.

For analyses associated with the vulture anthrax study, please cite the manuscript listed above once published. Until publication, please reference this repository and the relevant code version.

Citation of the code helps ensure appropriate attribution to the researchers who developed the analyses.
