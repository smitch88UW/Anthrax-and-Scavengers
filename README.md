# Anthrax-and-Carnivores
Published code for carnivore anthrax mitigation

Code in this repository is affiliated with math and epi models incorporating carnivores into anthrax outbreaks. Manuscripts affiliated with this repository include:

1.) Mitchell S, Flaxman A, Laubach Z, Holekamp K, Meisner J. A One Health model evaluating the role of a wild carnivore in mitigating multi-host anthrax outbreaks. (2026) Scientific Reports. (UNDER REVIEW).

2.) Kendall C, Mitchell S, Crews S, Steers K. The role of individual vulture behavior in controlling an anthrax outbreak. (In Prep for a 2026 submission to Ecosystem Services)
